# Web 接口请求精简

## 行为与范围

仅修改 Web，不改变 Proxy 请求格式、IndexedDB 格式、学习交互、评分、收藏和词级业务保存。

- `reportEvent` 跳过 `strategy_study_enter`、`choose_in_recite_click`、`topic_wiki_show`。完成事件、打卡、完成计划、`saveStudyRecord`、`updateDoneData` 保留。
- 复习不再请求当前页面未消费的 `study/settings`、`creditStatus`、`studyRecord`。
- 前台和联网唤醒只检查当前词书、有待传数据的词书；普通检查按版本决定是否拉取。无待传的前台检查冷却 60 秒，有待传且已有退避计时器时不额外启动重试；联网恢复和显式同步不受冷却限制。
- 403 返回 `pauseReason: permission`，暂停自动同步并保留队列，页面提示权限恢复后手动同步。手动按钮传入 `userInitiated: true`，再次失败则再次暂停。账号会话改变时清理旧暂停状态。
- 普通错误使用 2、5、15、30、60、300 秒退避，之后每 300 秒一次。重试使用普通版本检查，未知版本仍保留 `needsFullPull`。
- 词表元信息仅缓存当前账号最近一个完整成功批次，10 分钟后失效；有序 TopicKey 的 book/tag/id 都参与匹配。进行中同批次请求合并，失败、不完整响应不缓存，显式重载绕过已完成缓存。缓存不包含学习分类或收藏状态，不持久化。
- Dashboard 的统计计算与网络加载分离；后台同步其他词书不获取 roadmap。

仍保留本地逐题事务、去重、冻结批次、上传中新增量、租约、50 个不同 topic 触发上传、800 条批次上限和上传后强制对账。没有通用缓存框架、离线资源系统或新增后端路由。

## 2026-11-28 真实验收

使用 ego-browser 在 `http://localhost:5173/page/dashboard` 及关联页面操作真实账号、真实接口。观察器仅统计 XHR 的路径、事件名称、状态码，没有模拟、拦截或替换接口响应，也未收集认证信息。

| 场景 | 实际请求 |
| --- | --- |
| 五词三阶段学习，15 次作答 | 13 次 API 请求，其中 `reportEvent` 只有两个完成阶段事件，`updateDoneData` 一次且结果码 0 |
| 二十词选择及拼写，40 次作答 | 32 次 API 请求，其中 `saveStudyRecord` 20 次全部成功、`reportEvent` 一个完成事件、`updateDoneData` 一次且结果码 0 |
| 两次进入当前词书词表 | 元信息请求共 1 次，第二次命中缓存 |
| 连续三次前台事件 | 新增 1 次版本查询，没有全量学习列表请求 |

计数区间是进入对应流程至整组同步完成，排除随后人工执行的数据核对请求；本地开发环境启用了 StrictMode，因此仍包含开发模式下重复的计划读取。这些数字是本次流程的实际观测，不是生产环境所有场景的固定请求数。

三类细粒度埋点及三个辅助读取均未发送。二十词顺利复习对应原先约 80 次细粒度埋点，本轮为 0；词级保存、打卡、完成计划和上传没有被误删。

完成真实收藏 `cunning`，确认服务器词表包含该词后，通过界面取消收藏，再确认三个用户单词本恢复原始归属。学习与复习结果进入服务器学习列表，词书已学数更新为 210，队列归零，上下行版本一致。逐词对照开答前的预期累计次数、错误数和轮次，并检查本地与远端的分数及三项能力分，25 个 topic 无差异；耗时回读限制见下节。

最终代码稳定后重新进入页面：两次词表访问的元信息请求仍共 1 次，连续三次前台事件只新增 1 次版本查询。全量 23 个测试文件、199 项测试通过，生产构建、改动文件 lint 和差异检查通过；暂存区、HEAD、stash 引用未改变，未提交或推送。

观察到 `learnedWords.used_time` 对本轮和优化前的记录均回读为 0，而本地累计有效耗时保留非零值。本轮没有改变耗时写入、转换或合并协议，不将这一回读行为作为请求优化修复内容，也不宣称远端耗时与本地相等。计数、错误数、分数及轮次另行逐词对账。
